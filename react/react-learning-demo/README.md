# React Learning Demo

This is a simple React learning demo project that showcases the basic structure and components of a React application.

## Project Structure

```
react-learning-demo
├── src
│   ├── components
│   │   └── Greeting.jsx
│   ├── App.jsx
│   ├── index.css
│   └── main.jsx
├── .gitignore
├── index.html
├── package.json
├── vite.config.js
└── README.md
```

## Getting Started

To get started with this project, follow the steps below:

1. **Clone the repository**:
   ```
   git clone <repository-url>
   cd react-learning-demo
   ```

2. **Install dependencies**:
   ```
   npm install
   ```

3. **Run the application**:
   ```
   npm run dev
   ```

4. **Open your browser** and navigate to `http://localhost:3000` (or the port specified in the terminal).

## Components

- **Greeting**: A simple component that takes a `name` prop and displays a greeting message.
